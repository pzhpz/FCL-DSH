# FCL-DSH 启动器

> 基于 Kotlin/Compose 开发的仿 FCL 风格 DSH 启动器。原生拉起 Node 进程，支持实例独立、一键打包迁移与会话管理。

## 📱 核心特性
*   **极速原生启动**：免 PRoot 负担，直接通过 `linker64` 拉起 Node 进程。
*   **物理级多实例隔离**：每个实例拥有独立的 `core` 与 `home`，环境互不干扰。
*   **插件/技能市场**：内置资源市场，支持 MCP、插件、Skill 的独立导入与热更新。
*   **交互式主页**：内置可交互的动态元素（大肥鱼），等待你的调戏。
*   **一键分享方案**：支持生成/粘贴环境配置文本，轻松复刻别人的工作流。

## 🚀 下载与安装
请前往 [Releases](你的releases链接) 页面下载最新的 `.apk` 安装包。
> **⚠️ 注意**：由于包含 Node 核心环境，首次启动需下载/导入相应的运行库，请关注软件内引导。

## 🛠️ 编译指南
本项目使用 Kotlin 及 Jetpack Compose 开发。
1. 克隆本仓库。
2. 使用 Android Studio 或 CodeAssist 打开。
3. 执行 `gradle assembleDebug`。
